# Security

Supported framework releases receive security fixes on the current `0.2.x`
line. Versions before `0.2.0` are unsupported.

Please report security issues privately through the repository's GitHub private
vulnerability reporting form:

<https://github.com/global-torque/torque-packages/security/advisories/new>

Do not include credentials, personal data, production URLs, or real investment
records in reports or fixtures. Include the affected package and version, a
minimal reproduction, and the impact when safe to do so.

This repository contains client-side framework code. Hosts remain responsible
for authentication, authorization, service origins, environment loading, and
provider configuration.
